## Collisions and exclusions

**CRT/Windows identifier collisions: 0.** `gen_bindings.py` carries a
conservative reserved-identifier list (CRT stdio/stdlib/string/math/time/ctype
function names, `windows.h` object-like macros such as `min`/`max`/`small`/
`far`/`near`/`interface`, and C keywords) and would *skip* emitting a macro
for any game-scope name that matches, reporting it in the generated header
(`/* SKIPPED: ... */`) and in the JSON summary the generator prints, instead
of INTEROP_NOTES.md's rename-the-type-name approach (`FILE`->`it_orig_FILE`):
a plain-name `#define` cannot be renamed without breaking the reason it
exists (src/ must be able to write the literal identifier), so an actual
collision here would need per-name resolution before that function/global
could be promoted, not an automatic rename. As of this run the 398-name
game-scope surface (156 globals + 242 functions, disjoint) has none.

**`--exclude` (opt-out for functions being compiled natively):** verified
with `python gen_bindings.py --exclude play,update_player,blit_to_screen`
against a scratch output -- all three names were omitted from the emitted
`#define`s (left as `/* excluded by --exclude (compiled natively): <name> */`
comments) while the other 239 functions and all 156 globals were emitted
normally. The delivered `pf_bindings.h` in this directory was generated with
an empty exclude list (no function in src/ is promoted yet).

## How the carrier build uses it

```
cl ... /Icarrier\gen /FIcarrier\gen\pf_bindings.h src\icytower\*.c
```

`/FI` force-includes `pf_bindings.h` before any of src/'s own tokens are
preprocessed, so every plain name src/ declares as an ordinary extern
(`extern int reward_scale;`) or calls directly is already a macro expanding
to `(*(T*)VA)` / `((PFN_name)VA)` by the time the compiler sees it -- no
address literal, no carrier type, ever appears in src/ (enforced by
`scripts/check_native_layer.py`). When a function is promoted to NATIVE and
compiled with its own definition into the carrier, its name is passed on
`--exclude` so `pf_bindings.h` does not also try to redirect it to its own
original address:

```
python carrier\gen\gen_bindings.py --exclude foo,bar,baz
cl ... /FIcarrier\gen\pf_bindings.h src\icytower\foo.c src\icytower\bar.c ...
```

Standalone (src/ built outside the carrier, e.g. for unit tests), `/FI` is
omitted entirely and a `state.c` defines storage for the same externs
(win32_pilot.md §7a); see `bindings_selftest.c` below for the mechanism that
makes one `.c` file work both ways.

## Selftest results

Fixture: `carrier/gen/bindings_selftest.c` (+ `selftest_state.h` /
`selftest_state.c`) -- one address-free function using real names from this
run (`reward_scale` : `fixed`, VA 0x4fac28; `player_id` : `int`, VA
0x4fe518; `ply` : `Tplayer *[1000]`, VA 0x4ff128):

```c
void selftest_bump(void)
{
    reward_scale += 1;
    ply[player_id]->x += 1;
}
```

(`ply[i]->x`, not `ply[i].x`: DWARF gives `ply`'s real type as an array of
1000 `Tplayer *`, not an array of `Tplayer`, so pf_bindings.h's macro casts
to `Tplayer *(*)[1000]`, matching `it_globals.h`'s `IT_G_ply` exactly.)

`selftest_state.h` declares the same three names as ordinary externs but
only when `PF_BINDINGS_H` is **not** already defined -- an object-like
`#define reward_scale (*(fixed*)0x...)` makes any subsequent `extern fixed
reward_scale;` line invalid C (the macro expands inside the declarator), so
the extern declarations must be absent whenever `pf_bindings.h` has already
been forced-included, and `PF_BINDINGS_H` (pf_bindings.h's own include guard)
is exactly the signal that has already happened.

Both builds run with `vcvars32.bat` (32-bit MSVC 2022):

| build | command | result |
|---|---|---|
| carrier world | `cl /nologo /c /W3 /TC /FIpf_bindings.h bindings_selftest.c` | 0 errors, 0 warnings |
| standalone world | `cl /nologo /c /W3 /TC bindings_selftest.c selftest_state.c` | 0 errors, 0 warnings |

Both produced `.obj` files (`selftest_carrier.obj`, `bindings_selftest.obj`,
`selftest_state.obj`) in this directory. The same `bindings_selftest.c`
source, byte-for-byte, compiled in both worlds -- the SS7a contract holds.
