# Agent scratch notes (archived 2026-09-08)

Working notes written by subagents during the pilot, copied from the
session scratchpads so that nothing of the record depends on temporary
directories. Their findings were consolidated into carrier/NOTES.md,
src/icytower/PROMOTIONS.md, INVIVO.md and notes/living_record.md, which are
authoritative; these files are kept as evidence of the reasoning only.
Larger scratch inputs (annotated disassembly listings, probe scripts,
vector files) are in artifacts/scratch_archive/ (gitignored, regenerable).
