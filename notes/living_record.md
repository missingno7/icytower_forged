## Determinism model
- 2026-09-07 HOST ENUMERATIONS ARE A CHANNEL (KNOWN by measurement, divergence 009, carrier/NOTES.md 'Divergence 009'): a host device ENUMERATION reaches the 151-global digest domain WITHOUT any of its values being hashed — the guest allocates one arena block per enumerated item, sized by that item's name, from the same shared deterministic arena the game allocates from, so every arena pointer in the digest domain is displaced (27 of the 151 globals hold one; 19 measurably moved). Rule now written down generically in carrier/win32_policy.json digest_domain.host_enumeration_policy: in a carrier-owned run the carrier performs the enumeration itself and delivers a CONSTANT carrier-owned list, passing through only an opaque host handle that is provably outside the digest domain. First instance normalized: dsound.dll!DirectSoundEnumerateA (det_wrap_DirectSoundEnumerateA; knobs DET_ISOLATE_OFF=dsound, DET_DSOUND_DEVICES=N; --report now carries environment.dsound_host_names so the host's real list is on record).
